# Dependencias de la matriz YOLOv26 — CascoVision
# Entorno validado: Python 3.12

# --- Orden de instalación (respetar el orden) ---

# 1) PyTorch con CUDA. En Windows el build con GPU NO está en PyPI: el de PyPI
#    es CPU-only (~118 MB) y tu tarjeta quedaría sin usar. Sin esto, pip además
#    intenta compilar desde código fuente y falla sin Visual Studio.
pip install torch==2.14.1+cu126 torchvision==0.29.1+cu126 --index-url https://download.pytorch.org/whl/cu126

# 2) Ultralytics. La versión 8.4 o superior es obligatoria: best.pt se entrenó
#    con yolo26s.pt y las versiones anteriores no resuelven ese checkpoint.
pip install ultralytics==8.4.177

# 3) OpenCV. El techo 5.0 es necesario: la 5.x eliminó por completo la API de
#    cascadas Haar (cv2.CascadeClassifier ya no existe).
pip install "opencv-python>=4.6.0,<5.0"

# 4) NumPy. Nunca fijar por debajo de 2.4: no hay ruedas cp315 y pip intentaría
#    compilarlo, lo que requiere Visual Studio Build Tools.
pip install "numpy>=1.24"

# 5) Métrica de tracking, que Ultralytics intenta instalar en caliente durante
#    la ejecución. Se fija aquí para que no se descargue a mitad de una demo.
pip install "lap>=0.5.12"
